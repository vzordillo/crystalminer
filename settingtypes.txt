# The model behind the AI tutor (Prism's chat, /ask and /symmetry with a description), named as in LiteLLM: provider/model.
# deepseek/deepseek-flash (the default) or deepseek/deepseek-v4-pro: DeepSeek, key in DEEPSEEK_API_KEY.
# anthropic/claude-opus-5-5: Claude, key in ANTHROPIC_API_KEY or the Anthropic API key below.
# openai/..., gemini/..., groq/..., mistral/..., openrouter/<org>/<model>, together_ai/..., xai/..., fireworks_ai/..., perplexity/..., cerebras/...: hosted services, each with the key variable LiteLLM uses (OPENAI_API_KEY, GEMINI_API_KEY, GROQ_API_KEY, MISTRAL_API_KEY, OPENROUTER_API_KEY, TOGETHERAI_API_KEY, XAI_API_KEY, FIREWORKS_AI_API_KEY, PERPLEXITYAI_API_KEY, CEREBRAS_API_KEY).
# ollama/llama3.2, lm_studio/..., hosted_vllm/...: a server on this computer or your network, no key needed.
# litellm_proxy/<model>: any model a LiteLLM proxy serves (Bedrock, Vertex AI, Azure and the rest), at LITELLM_PROXY_API_BASE (default http://localhost:4000) with LITELLM_PROXY_API_KEY.
# Empty: the environment variable CRYSTALMINER_TUTOR_MODEL, else deepseek/deepseek-flash. The server must also list crystalminer in secure.http_mods.
crystalminer.tutor_model (Tutor: model, as provider/model) string deepseek/deepseek-flash

# Usually auto: the provider is the prefix of the model above. A provider's name (deepseek, anthropic, ...) lets the model above be given without its prefix. openai_compatible: any server with an OpenAI-style Chat Completions API at the base URL below, with the model's name sent exactly as written.
crystalminer.tutor_provider (Tutor: provider) enum auto auto,openai_compatible,deepseek,anthropic,openai,gemini,groq,mistral,openrouter,together_ai,xai,fireworks_ai,perplexity,cerebras,ollama,lm_studio,hosted_vllm,litellm_proxy

# Anthropic API key, for anthropic/... models. Paid per request through the Claude API. ANTHROPIC_API_KEY is used when this is empty.
crystalminer.anthropic_api_key (Tutor: Anthropic API key) string

# Address of the API, up to and including /v1, when it is not the provider's usual one: for openai_compatible, hosted_vllm, a proxy, or a server elsewhere. Ollama on this computer: http://localhost:11434/v1
crystalminer.tutor_base_url (Tutor: base URL) string http://localhost:11434/v1

# API key for the model's provider, sent as "Authorization: Bearer <key>". When empty, the provider's own variable (DEEPSEEK_API_KEY, OPENAI_API_KEY, ...) and then CRYSTALMINER_TUTOR_API_KEY are used. Leave it empty for a local server such as Ollama.
crystalminer.tutor_api_key (Tutor: API key) string

# OpenAI-compatible provider: seconds to wait for an answer. Local models on a slow CPU may need more.
crystalminer.tutor_timeout (Tutor: timeout in seconds) int 60 5 600

# Materials Project MPContribs key for teacher-created live exhibits. The key is never shown or logged.
# The server must also list crystalminer in secure.http_mods. CRYSTALMINER_MP_API_KEY is used when empty.
crystalminer.mp_api_key (Live exhibit API key) string

# MPContribs API base URL for live exhibits.
crystalminer.mp_api_url (Live exhibit API URL) string https://contribs-api.materialsproject.org

# OpenAI-compatible provider: longest answer in tokens. When not set, /ask uses 400 and /symmetry 200.
# Models that think before answering need more, for example 2000; a cut-off answer is not shown.
crystalminer.tutor_max_tokens (Tutor: maximum answer length in tokens) int 400 16 4096

# Runs the automated checks in selftest.lua, then shuts the server down. For developers.
crystalminer.selftest (Run self-test and shut down) bool false

# Offer the short test of 11 questions when a new player joins (and again at the top tier), to
# measure what the game teaches. Answers are stored without names; /exportdata saves them.
crystalminer.pretest (Offer the pre- and post-test) bool true

# Keep it daytime, so colours and symbols stay easy to see.
crystalminer.always_day (Always daytime) bool true

# Play short, gentle sound effects (copies appearing, quiz answers, doors, portals, footsteps,
# jumping, placing and removing blocks). Footsteps, block and jump sounds change only after a
# restart of the world.
crystalminer.sounds (Sound effects) bool true
